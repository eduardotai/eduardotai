## Physics Playground

**[physicsplayground.com.br](https://physicsplayground.com.br)**

Interactive intro to physics. You play with a live simulation first, then see why it works, then the math is built from the numbers you just used. Lessons and sims in Portuguese and English. Foundations stay free.

Shipped in public on X ([@taisalless](https://x.com/taisalless)): launch with ~15 lessons, then Pro modules (rotation, fluids, heat, electricity), dozens of simulations, spaced repetition, glossary, companion math course, exercise bank, exams, and a small textbook library on the site.

## TTBR

**[ttbr.app](https://ttbr.app)**

Sim-racing coach for Brazilian iRacing drivers. A Windows agent records telemetry while you drive. The web app shows where you lose time: track map, throttle / brake / speed traces, and tips in plain Portuguese. Priced in reais, pay with PIX. Free tier plus Plus (posts list Plus at R$ 29,90).

Build log on X (Sep–Oct 2026): high PR throughput with Claude Code, CI hardening, stint-based sessions, unlimited Free uploads, map / start-line fixes, desktop agent releases.

Older cousin on GitHub: [setupforge](https://github.com/eduardotai/setupforge) (sim setups + AI coach in Portuguese).
